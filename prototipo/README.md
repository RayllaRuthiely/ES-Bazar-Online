# Protótipo navegável — fluxo de publicar anúncio (UC-01)

Protótipo interativo no Canva:
https://canva.link/8bqszf8nwpixohs

Versão em PDF de apoio: `prototipo.pdf`.

## Ordem de navegação
1. Login / Criar conta
2. Catálogo
3. Detalhes do produto (a partir de um card do catálogo)
4. Novo Anúncio (a partir do botão "Novo Anúncio" no catálogo)
5. Confirmação de publicação (a partir de "Publicar")
6. Meus anúncios (a partir de "Ver meus anúncios" na confirmação)
