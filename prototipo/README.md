# Protótipo navegável — fluxo de publicar anúncio (UC-01)

Este é o rascunho das telas do fluxo principal. Para virar protótipo navegável:

1. Montem em um arquivo de apresentação (uma tela por slide), com links de cada
   elemento clicável para o slide seguinte — ou em uma ferramenta com modo de
   protótipo (ex.: Figma gratuito).
2. Exportem o resultado em PDF e coloquem nesta pasta junto com o link, se usarem Figma.
3. Ordem de navegação: Meus anúncios → Novo anúncio → Anúncio publicado,
   com os dois desvios de recusa (dados incompletos / dados inválidos)
   saindo da tela "Novo anúncio" e voltando a ela.
